Question : où se crée la valeur dans un négoce BTP, entre les segments de clients, les familles de produits et les agences urbaines ou rurales ?

Modèle
Schéma en étoile : table de faits Ventes, dimensions Clients, Produits, Agences, Calendrier, avec Fournisseurs en flocon sur Produits.
Pages
Vue d'ensemble COMEXPerformance agencesProduits & clients
Techniques
Classements RANKX par agence et famille, part de CA par segment, CA YTD et trimestriel, carte régionale, filtres zone/région.
  • 65 %du CA provient des entreprises du BTP, qui ne représentent que 21 % des clients. Leur panier moyen atteint 7 500 €, contre 490 € pour les particuliers.
  • 65 %du CA annuel se concentre d'avril à septembre : la saisonnalité du chantier pilote les besoins en stock.
  • 48,8 %de taux de marge sur l'outillage électroportatif, première famille en CA (24 %) et en rentabilité. Le béton et mortier plafonne à 5,3 %.
Mesures DAX · extrait 
CA_Total =
SUMX ( Ventes,
    Ventes[quantite]
        * RELATED ( Produits[prix_unitaire] )
        * ( 1 - Ventes[remise_pct] ) )

CA_Segment_Pct =
DIVIDE ( [CA_Total],
    CALCULATE ( [CA_Total], ALL ( Clients ) ) )

Rank_Agence =
RANKX ( ALL ( Agences ), [CA_Total], , DESC )

Techniques
Évolution N vs N-1 avec indicateur ▲/▼, rang et part de CA par client, CA cumulé pour l'analyse de concentration, nuages de points CA, marge et volume.
  • +47 %de CA en 2025 après un recul de 22,8 % en 2024 : 4,6 M€ sur la dernière année.

Mesures DAX · extrait 
Rang_Client_CA =
RANKX ( ALL ( Clients ), [CA_Total], , DESC, Dense )

CA_Cumule_Client =
VAR RangActuel = [Rang_Client_CA]
RETURN
    CALCULATE ( [CA_Total],
        FILTER ( ALL ( Clients ),
            [Rang_Client_CA] <= RangActuel ) )
